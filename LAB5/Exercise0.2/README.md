# Lab 5 — Exercise 0.2

## Zero-Effect Pagination & Container Queries

This exercise explores derived pagination in React and responsive
component layouts using CSS container queries.

## Objectives

- Calculate pagination values directly from source data.
- Avoid redundant state and synchronization effects.
- Use stable evidence identifiers as React keys.
- Build flexible and accessible evidence components.
- Verify behavior through automated tests and browser checks.

## Technology Stack

- React 19
- Vite
- JavaScript
- CSS
- ESLint
- Vitest
- React Testing Library

## Getting Started

Install dependencies:

    npm ci

Start the development server:

    npm run dev

Run lint checks:

    npm run lint

Run automated tests:

    npm run test

Create a production build:

    npm run build
